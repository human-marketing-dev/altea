Grid-friendly card previewing one development. Used on the homepage grid and business-unit listing pages.

```jsx
<ProjectCard image="paseo-altea" unit="Comercial" title="Paseo Altea" location="Saltillo, Coahuila" stat="34 locales · 94% ocupación" />
```

`image` is an `<image-slot>` id — swap it per real project photography; never fabricate a stock image.
