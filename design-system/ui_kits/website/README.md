# Sitio web Altea — UI Kit

Recreación clicable del sitio web de Altea sobre los componentes del design system. Navegación por hash (`#home`, `#comercial`, `#industrial`, `#vivienda`, `#contacto`) — cada link de la NavBar y del Footer funciona.

- `Home.jsx` — portada: hero, resumen de las 3 unidades de negocio, proyectos destacados, banda de impacto (estadísticas de la presentación), CTA de contacto.
- `BusinessUnit.jsx` — plantilla reutilizada para Comercial / Industrial / Vivienda (copy y stats reales de `Altea-Identidad.pdf` y `Presentación ALTEA`).
- `Contact.jsx` — formulario de contacto con estado de envío simulado.

Todas las fotografías son `<image-slot>` — reemplázalas con fotografía real de los desarrollos antes de publicar.
